# Hi, I'm Crhistian Vergara

Full-stack and mobile software engineer from Palmira, Colombia. My experience isn't a fixed stack: over ten years, each project pushed me into a new layer, and learning what that layer required became part of the job.

[Portfolio](https://krisskira.github.io/krisskira/) · [LinkedIn](https://www.linkedin.com/in/cristian-david-vergara-gomez/) · [Email](mailto:krisskira@gmail.com) · [Leer en español](README.es.md)

## How I got here

- **2016–2019 · From the sensor to the screen.** I started out programming PIC microcontrollers in C and building Kriver SmartHome, a home-automation project controlled from the browser. That meant building the web side too: PHP, JavaScript and eventually my own MVC framework.
- **2019–2023 · Mobile, then architecture.** Mobile became daily work: fintech and e-commerce apps in React Native. As they grew, I learned Clean Architecture and DDD so the team could keep building on the code, and I carried those ideas into TypeScript, React/Cypress and Django/Docker projects.
- **2023–2024 · Where the problem actually was.** The same period asked for React Native, native iOS and a Python/FastAPI backend. Refactoring the MongoDB queries cut response times, and SwiftUI with MVVM, Combine and MapKit let me contribute on both native and cross-platform work.
- **2024–2025 · Infrastructure and coordination.** After exploring AWS Cognito with Next.js, the work moved to React and AWS Lambda with SAM. I built a frontend template for new projects and coordinated the frontend so the team could deliver.
- **2025–2026 · Several products, the same way of contributing.** I collaborated across frontend and backend on different SaaS products and relational databases: reading systems I hadn't designed, learning each domain and applying what I already knew. I also brought AI into the workflow.
- **2026 · Back to hardware.** With all of that behind me, I returned to where I started: firmware, PCB, 3D-printed enclosure and a desktop app, all in one project.

## What that taught me

- To see a system end to end, from firmware to interface to data.
- To structure code so it survives change, whatever the language.
- To read systems I didn't design and contribute within their rules.
- To work within hard limits: my latest firmware uses 16,382 of 16,384 bytes of flash.

## What I build

- **[HotPlate](https://github.com/krisskira/smd-soldering-hotplate)**: an SMD reflow station with PI control, its own display and a desktop app. *C · ATmega16 · KiCad · Python*
- **kLog** *(in development)*: self-hosted logs and events for applications and devices. *Go · GraphQL · PostgreSQL · Redis*
- **[GIF → ST7920](https://github.com/krisskira/st7920-image-gif-to-bytes)**: turns GIFs into C arrays for 128×64 displays on memory-constrained MCUs. *Python*
- **[Handwritten digit calculator](https://github.com/krisskira/ml-handwritten-number-recognizar)**: my way into machine learning. *Python · Keras*
